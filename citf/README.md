## 论文与实验

当前保留候选动作交互与整队联合融合，团队价值使用实际执行推力和真实回报学习。主入口为 `code/unified`；旧单艇干预差分、教师程序和直接推力PPO保留历史身份。

三项贡献依次为完整融合防御方法、候选交互Adapter及训练机制、系统验证。同一周期的候选共享学习端点，每艇一个标量共同融合双推进器；联合生成、实际动作Q、连续配置改进、反馈学习和端点更新构成当前实现。主体及基线正在开发训练，结果和下一步见任务文档。

公开对照为ARBoids、RP、SAC、Boids；两项消融为去动作交互与去生成器反馈。6个学习版本各5种子，共30次主训练。冻结模型评价机动性1.5—3.0与2—7艇，另执行一条五阶段攻防链及CITF/ARBoids各100场VRX。完整范围见方案第六至七章。
