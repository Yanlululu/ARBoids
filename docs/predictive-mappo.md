# 预测驱动的两阶段 MAPPO

此实现使用固定三自由度模型预测候选动作的交互，通过可训练关系编码和协调头影响随机 Adapter，再用任务优势与碰撞成本优势训练提案和门控。防御艇共享 Actor；Critic 集中训练，部署不使用 Critic。

## 控制链路

一次控制周期为：观测 → 各艇生成 Boids/学习候选 → 同步交换消息 → 名义运动推演 → 艇对关系编码及协调 → 采样门控 → 执行融合推力。

- `train/policy/mappo.py::PredictiveMAPPO.act` 是训练、评估和 VRX 的共同策略入口。
- 原始学习动作 `v` 服从二维高斯，归一化候选为 `tanh(v)`。
- 消息包括艇 ID、时间戳、`[x,y,yaw,vx,vy,yaw_rate]`、两个归一化候选。启用 `compatibility_peer_intent` 时，还在这一轮交换各艇当时的原始 Actor 观测，供接收艇复算临时融合意向；不发送 Critic 状态或神经网络隐特征。第一版采用同步可靠的全队交换，不含延迟、丢包或带宽优化。
- `InteractionPredictor` 从测得的地速初始化零海流名义模型，每艇保持两个候选推力分别推演。默认窗口 2 秒，子步 0.05 秒；积分顺序与原 `WAMV` 相同。不会读取未来扰动，也不会推进真实环境。
- 每个有向艇对有 18 个原始特征：BB、BL、LB、LL 各自的最近距离、最近时刻、接近趋势，加本艇坐标系下的相对位置、相对速度、相对航向正弦/余弦。距离、时间和速度使用固定尺度。
- 关系编码和 masked attention 产生 `z_pred`。共享成对网络产生 `eta_ij = sigmoid(g(e_ij)-g(e_ji))`，再汇总为 `z_coord`。双方协调信号互补；这不是全队无碰撞保证。
- 默认 Adapter 输入为状态特征 512 维、动作编码 128 维、关系特征 64 维、协调特征 16 维。输出门控高斯的均值和对数标准差。
- `w` 为门控原始采样，`theta = sigmoid(w)`。测试用两个高斯的均值作确定性决策。

推进器执行保持原公式：`F_exec = theta * F_L + (1-theta) * F_B`。
网络动作与推力的换算为 `F = 750*a + 250`，因此归一化动作零不是零推力。预测器与执行器使用相同换算。

## 概率梯度和训练目标

默认采用**分因子裁剪的 MAPPO 扩展**：提案与条件门控分别构造 PPO ratio，各自裁剪，再求和平均；二者使用相同的团队综合优势。这是局部因子 surrogate，不等价于对全队联合概率比进行裁剪。

性能入口的 `--joint-ratio` 可显式切换为每个控制时刻全队两阶段的联合概率比：先将所有艇提案和条件门控的新旧对数概率差求和，再取指数、进行一次 PPO 裁剪。KL 提前停止也相应检查这个联合分布。联合 surrogate 按艇数缩放，使其在旧策略处的 score gradient 尺度与原分因子实现一致；联合比并非跨整个回合相乘。使用哪种规则写入配置及 checkpoint，默认保持旧模型兼容。两种实现都保存原采样动作和消息，均未引入 SAC 的动作价值梯度。

PPO 数据保存原始采样 `v,w`、旧对数概率、观测、候选消息、原始艇对特征与 mask。更新时固定这些采样和消息，只重新计算当前状态编码、关系编码、协调头和门控分布；不重新采样候选，不复用旧的神经网络隐特征。

概率统一定义在原始高斯变量上；固定 tanh/sigmoid 变换的雅可比在新旧 ratio 中抵消。可选的 theta 空间门控在执行时将原始高斯样本裁剪至 `[0,1]`，其 PPO 仍评价保存的原始样本概率，不将该概率误称为裁剪后动作的密度。探索正则使用原始高斯的熵，不将其称为有界动作或 theta 的熵。没有 SAC 的 Q 动作梯度、温度更新、target Q、旧数据回放或额外 Adapter 噪声。

集中式 Critic 输入所有艇的位置、航向、相对水流速度、攻击艇机动参数与剩余时间，不接收本次提案或门控。它有独立的任务/成本价值头，与 Actor 不共享参数。

任务奖励是各艇 `(main + formation)` 的均值，移除原固定碰撞惩罚。首次实际队内碰撞为团队成本 1，一个回合最多一次；独立读取物理事件，因而同时发生突破与碰撞时仍计成本。

默认 `reward_gamma=cost_gamma=1`，对应有限回合任务收益和碰撞事件概率。两套 GAE 使用各自价值输出，先计算 `A = A_reward - lambda*A_cost`，然后统一标准化 A，不分别标准化两个优势。GAE 的 lambda 与碰撞约束乘子是不同参数。

一个 rollout 收集固定行为策略下的一批完整回合，保留每一帧的全队维度。所有 PPO epoch 使用同一个碰撞乘子。更新结束后仅执行一次：

```text
collision_rate = 碰撞回合数 / 完整回合数
lambda_next = max(0, lambda + lagrange_lr * (collision_rate - collision_budget))
```

没有使用预测风险替代真实成本，没有按艇数重复累计成本。`done=4` 是任务时限到达，在当前任务中计守时成功，并按真实终点令 bootstrap 为零。第一版不在回合中间切断采样，因此总步数可能超出设定上限一个完整 rollout。

## 运行

### 性能训练与验收

性能开发入口为 `train/train_mappo_performance.py`，配置为 `train/configs/mappo-performance.yaml`。它只做性能训练和验收，不自动开展正式对照实验。

- 使用已有论文参数 SAC Actor 初始化：迁入状态编码、学习候选和原 Adapter 权重，以 `sigmoid(2x) = (tanh(x)+1)/2` 精确转换原门控。预测 Adapter 对门控 logit 的新增量初始为零，随后参与 PPO。没有载入 SAC Critic、Q 梯度或 SAC 优化器。
- 此初始化模式沿用基线的 LeakyReLU 和原观测尺度；原来的随机初始化 Tanh 模式仍可用。初始化来源属于训练条件，后续正式比较必须明确报告并给对应对照使用相同条件。
- CPU 常驻进程收集完整回合，GPU 负责单一学习器更新。每批采样使用同一份不可变策略权重，所有回合收齐后才更新；每回合使用独立种子。
- `--environments-per-worker 4` 可在每个 CPU 进程内批量处理四个独立训练场景，共用网络前向和向量化候选轨迹预测。每个场景保留自己的环境、NumPy/Python 随机状态和 Torch 策略随机数生成器；提前结束的场景由下一个训练种子补位，场景之间不建立艇对关系。保存的原始动作、消息和旧概率仍对应实际采样，失败场景前缀可逐值复原。神经网络批量矩阵乘法可能有 float32 舍入差异；确定性开发验证、基线和独立验收继续使用原逐场景路径，维持已有比较口径。默认 1 兼容原采样方式。
- 同一决策或同一个 PPO 小批量中，两阶段共享一次状态编码结果。复用仅限当前调用，保持共享计算图，不跨控制步或参数更新缓存；回归检查覆盖对数概率和两阶段梯度的一致性。
- 艇体动力学在构造常量矩阵时缓存原来的加速度求解矩阵，并在同一子步内复用坐标变换。已与修改前源码对照三种机动参数、2,400 个控制步，状态逐步完全一致；这种计算复用独立于策略算法。
- 先用实际完整回合回报拟合两个价值头。任务价值内部按 100 缩放，计算 GAE 时还原原单位；碰撞成本和 `A_R-lambda*A_C` 的定义不变。该调整平衡价值拟合的数值尺度，不是分别标准化两类优势。
- PPO 可用 `target_kl` 在近似 KL 超限后停止本批后续 Actor 更新，Critic 继续拟合。它是提前停止阈值，不是单次梯度步的严格 KL 上界。
- `--full-batch-guard` 在每轮 PPO 优化后重新评价整批保存的动作和消息，以本批综合优势的裁剪目标选择满足 KL 阈值的最佳轮次。若最后一次梯度步已越界，恢复此前合格的 Actor 权重及完整 Adam 状态；最后一轮不如前面的轮次时，同样保留较好的轮次。Critic 继续拟合本批真实回报，乘子仍只按正常完整回合更新一次。可与较大的 `--ppo-epochs` 配合，增加每批样本的有效利用，避免只靠增加采样量。记录最终 KL、目标增量、选中的轮次、保留的更新次数和是否回滚。该检查复用训练数据，不增加环境验证回合；它约束的是训练批上的经验 KL 和 surrogate，不等于实际成功率或碰撞率保证，最终性能门槛保持不变。默认关闭以保持旧 checkpoint 的训练行为。
- 可用 `--prediction-lr` 为关系编码、协调、Adapter 和门控均值头单独设置微调速率，各参数组分别裁剪梯度，避免继承的网络压低新分支的梯度。改变速率会保留各参数的 Adam 动量并重新开始稳定性计数。
- `--prediction-eps` 可单独调整该参数组的 Adam epsilon，用于检验很小的协调梯度是否被数值稳定项过度压低。默认仍为 `1e-5`，继承参数组保持原值；显式调整保留所有动量并重新开始稳定性计数。梯度尺度改善不等于性能达标，仍须经过同一套验证。
- `--backtracking-steps 8` 在本批所有 Actor 更新均被完整批保护拒绝时，用同一批完整回合重新计算一次完整策略梯度，并最多尝试八个逐次减半的 Adam 步长。每个尝试都从同一份不可变的参数、Adam 步数及矩快照出发；被拒绝的尝试不累计优化器状态。只有完整批 PPO surrogate 改善且 KL 合格时接受一步，所有尝试失败则完整恢复。Critic 不在回溯中重复更新，实际事件乘子仍在整批结束后更新一次。配置中的学习率保持原值，实际接受比例另记为 `full_gradient_step_scale`；`policy_epoch_selected=-1` 表示接受的是完整批回溯步。默认零关闭，已有 checkpoint 的更新规则保持兼容。它解决大步反复回滚造成的停滞，不替代独立场景的性能验收。
- `--gate-std-lr` 可为条件门控的方差头设置独立学习率，使其通过同一个 PPO 目标学习探索范围，而不必随继承参数使用极小的微调速率。默认 0 保留旧分组；显式启用时按参数迁移 Adam 状态，保存和恢复新的分组。
- `--ppo-epochs` 显式设置每批 on-policy 数据最多复用多少轮，KL 提前停止仍然生效。训练指标同时记录实际 Actor 更新次数、门控裁剪比例、两类优势尺度和更新前价值解释方差；回报方差为零时不报告解释方差。
- `--gate-std` 调整门控的初始探索，`--baseline-proposal-std` 恢复基线 Actor 学到的条件提案方差；它们保持确定性初始动作不变，变化保存在 checkpoint 的训练状态中，并清除被重设方差头的旧动量。每次重设后重新采集完整 on-policy 数据。
- `--baseline-gate-bound` 是另一种显式的迁移初始化：将继承门控的 logit 限制到指定正负范围，清零预测分支的均值输出头，并用新策略的实际完整回合重新拟合双 Critic。它会改变初始确定性动作，不能称为精确复制基线。限制只作用于继承项，可训练预测分支的均值增量和最终 theta 均未被该范围截断，后续仍按两阶段 PPO 更新。此初始化条件必须随正式对照报告。
- `--new-gate` 保留学习提案及编码器，清零继承门控与预测门控的均值输出，令初始确定性 theta 为 0.5，再通过 PPO 学习门控；只清除被重设参数的优化器状态并重新拟合双 Critic。它与门控范围初始化互斥，会改变初始行为；继续同一训练时不要重复传入该重设选项。
- `--theta-space-gate` 是针对 logit 端点探索不足的可选参数化，旧配置仍使用 sigmoid-normal。它复制当前预测均值头为固定参数的锚定头，并清零新的增量头，使初始确定性动作逐值保持一致；共享编码与 Adapter 仍可训练。新策略为 `mu_theta = sigmoid(inherited_logit + prior_head(features)) + delta_head(features)`，采样 `v ~ Normal(mu_theta, sigma_theta)`，执行 `theta = clip(v, 0, 1)`；默认初始 `sigma_theta=0.1`，可用 `--gate-std` 显式指定。这样增量和探索直接作用于融合比例，不被原有 sigmoid 端点压缩。保存的是未经裁剪的 `v` 及其 Gaussian 对数概率，PPO 重算同一个潜变量的概率比，不能把裁剪后的 theta 代入 Normal 概率；这仍是策略概率梯度，没有动作价值梯度。裁剪执行、保存原始 Gaussian 动作的处理也可见 [SB3 的 on-policy 采样实现](https://stable-baselines3.readthedocs.io/en/master/_modules/stable_baselines3/common/on_policy_algorithm.html)。此模式会改变探索分布，须重新采集 on-policy 数据、拟合双 Critic 并重新开始稳定性检查；转换只做一次，续训省略该开关。它与其他门控重初始化选项互斥，checkpoint 保存模式和锚定头，旧 checkpoint 行为不变。
- `--cost-gae-lambda 1` 用整回合真实二元碰撞结果拟合成本价值、计算成本优势，任务优势仍使用自身 GAE；`--lagrange-lr` 显式调整乘子响应速率，碰撞预算保持原值。默认成本 GAE 参数仍为 0.95，以兼容原 checkpoint 的继续训练。
- `--cost-monte-carlo-targets` 将成本 Critic 的监督固定为真实、完整、未折扣的剩余碰撞事件成本，同时允许 Actor 使用较低的成本 GAE 参数降低梯度方差。这不会降低碰撞成本或改变乘子统计；价值估计不准确时，较低 GAE 仍有常规的偏差与方差折中，必须用实际成功率和碰撞率验证。默认关闭以保持旧配置的训练行为。
- `--episodes-per-update` 和 `--minibatch-size` 可增加一轮中实际采集的完整回合数及优化小批量，降低稀少碰撞样本造成的更新噪声；修改后重新计算稳定性，验证回合数与验收阈值不变。
- `--collision-branches 128 --branch-lookback 20` 可在正常采样之后，额外采集本轮训练碰撞前 20 个控制步（4 秒）的恢复分支。通过原种子和保存的实际动作重放前缀，并逐值核对观测和中央状态；随后复制完整物理环境，保留剩余任务时间，重新采样当前策略动作与独立海流，执行至实际终止。训练只使用新分支自己的结果，不使用原失败轨迹作为未执行动作的标签，不重放旧 PPO 损失。分支来自训练种子，每轮重新采集；不使用验证或验收场景。这是额外偏重风险状态的课程训练分布，正式对照必须披露或统一这个训练条件。PPO 和双价值头学习正常回合与这些当前策略分支；拉格朗日更新只统计正常初始分布的完整回合。指标分别记录正常任务、恢复分支、用于学习的步数和前缀恢复开销。它只由性能训练入口支持，正常续训省略开关即可恢复保存的设置，显式传 0 可停止课程采样。
- 开发验证与原基线使用同一组 200 个场景种子，要求成功率不低于基线、碰撞率严格低于基线且不超过 5%；碰撞率持平不能通过。连续三次验证通过后，才在另一组 200 个场景上做基线与新策略的成对验收，使用该组场景的基线结果重新比较。捕获、守时、突破和碰撞分别保存；验收失败不会被当作达标。
- 扩大的开发集可在基线清单中提供显式 `seeds`，用 `--eval-episodes` 指定匹配的数量；`protected_reference` 保留原 200 场景的独立成功率、严格碰撞改善和 5% 门槛，整体均值改善不能掩盖该子集退化。已看过的验收场景只能转为开发数据，下一轮须预留未用过的场景；`--audit-episodes` 可设置更大的独立成对验收数量。扩展开发集选模时，先要求成功率不降，再优先降低真实碰撞率。
- `--eval-interval` 从当前更新开始设置完整验证的间隔，减少短训练后反复评估的开销；阶段结束仍执行一次验证。修改间隔会重置连续达标计数，正常续训时省略该参数即可延续原计数和计划。
- `criteria.json` 固定验收条件，`best-validation.pth` 保存验证候选，`qualified.pth` 只在独立验收通过后产生。模型文件与指标保存在当前运行目录；正式测试场景不用于调参。

性能开发也可显式使用 `--stable-checks 1`：先同时通过开发集及受保护子集的门槛，立即冻结该模型，在预留新场景中做独立成对验收后停止。该流程确认固定模型的跨场景表现，不声称通过了三次训练快照检查；成功率不得低于同场景原基线、碰撞率严格改善且不超过预算的要求保持不变。有限回合的比例是统计估计，单次独立验收通过也不能证明全局最低碰撞率或所有工况的保证。已查看的验收种子必须标记为已使用，不能再次作为全新验收。

### 候选相容性与拦截分工直接影响门控

可选的 `compatibility_prior` 为 theta 空间 Adapter 增加一个可解释的预测分支。仅增加任意关系特征，仍需要稀疏碰撞经验教会网络哪一类候选更安全；该分支直接计算两种本艇候选之间的预测风险差，再交给策略分布和任务经验共同决定融合比例。

将 BB、BL、LB、LL 的预测最近距离还原为米，定义 `risk(d) = max(0,(7-d)/1)`。每个艇对的差值为 `0.5*(risk_BB+risk_BL-risk_LB-risk_LL)`；正值表示本艇学习候选的平均预测风险较小。这里对队友两个候选各取一半是明确的先验，并非估计出的队友实际门控。邻艇权重按四种组合中的最小距离计算 `softmax(-min_distance/2)`，屏蔽自身后归一化，再对加权差值取 tanh，得到范围为 `[-1,1]` 的信号；没有邻艇时为零。所有候选组合超过 7 米时，这个新增分支严格为零，避免持续改变安全状态下的拦截动作。7 米是预测特征的提前响应距离，环境实际碰撞阈值仍为 5 米。

`compatibility_peer_intent` 用临时融合意向替代固定的各占一半：接收艇通过本轮交换的原始 Actor 观测、候选及预测特征，用同一个当前网络复算各艇尚未加入物理风险修正的门控均值，裁剪为 `theta_anchor`。艇对差值变为 `(1-theta_anchor_j)*(risk_BB-risk_LB) + theta_anchor_j*(risk_BL-risk_LL)`。这是根据临时意向对端点风险插值，并不是连续混合动作轨迹的精确动力学预测，也不等于队友最终采样的 theta。计算只做一遍，不求循环固定点，不观察队友的最终门控样本，不增加第二轮通信。新增原始观测字段的通信开销应在正式对照中披露。

PPO 使用保存的完整队伍观测、原始候选和预测数据重新计算当前临时意向；不会把旧的网络均值缓存为固定消息，也不会 detach 这条计算图。门控概率对自身及队友意向网络的梯度均来自当前条件分布的对数概率，提案阶段仍使用原采样值及其概率。批量实现保留每个独立环境的完整队伍维度，不能在小批量中拆散一支队伍或混用其他环境的观测。

成对风险差还乘以拦截分工系数 `2*sigmoid((d_iA-d_jA)/5)`，然后再进行邻艇加权和 tanh 限幅。`d_iA` 是本艇到攻击艇的当前距离，`d_jA` 由本艇观测的攻击艇相对位置减去已交换的邻艇相对位置计算，不读取队友观测或 Critic。更接近攻击艇的艇减少该预测分支的调整强度，同伴更多承担调整；同一对艇的两个系数之和为 2，前提是双方像当前仿真一样获得同一攻击艇位置的同步一致观测。目标不可见或各艇目标估计不一致时，不能宣称仍精确互补。5 米是可配置的优先级温度，不与预测特征的归一化尺度混淆。这是具体的任务先验，未增加第二轮通信，已有可训练协调头仍参与 Adapter。

门控均值变为 `mu_new = mu_adapter + softplus(gain_raw)*compatibility_signal`，增益初始为 1。已有 Adapter、关系与协调网络均保留，增益加入预测参数组并接受同一 PPO 概率梯度。它作用在采样分布内部，未在动作执行后覆盖推力；训练与部署使用同一个入口。固定几何预测不需要反传，增益、关系编码与 Adapter 在评价保存的原始动作时可求导。启用时保留既有权重及 Adam 状态，新参数和所有尺度随 checkpoint 保存；默认关闭以兼容已有模型，原 SAC 对照显式关闭此分支和新增意向消息。`enable_compatibility_prior()` 默认启用 `compatibility_compact_risk=True`、`compatibility_task_priority=True`，意向加权是另行显式启用的选项 `peer_intent=True`，在验收入口对应 `--peer-intent`。直接写 YAML 配置时应显式设置对应布尔项。旧 checkpoint 缺少的开关均恢复为 False，保持各阶段候选的历史行为可复现。

`train/qualify_mappo.py` 可只启用这项结构修正并冻结候选，不增加优化器更新：

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 -u train/qualify_mappo.py --checkpoint train/experiments/predictive-mappo-performance-recovery42/predictive-mappo.pth --output-dir train/experiments/predictive-mappo-performance-new-candidate --compatibility-prior --workers 6 --audit-seed 60000 --audit-episodes 1000
```

命令中的输出目录必须尚不存在；已经用过的验收种子不能再作新验收，后续运行应选择未用过的区间。先检查冻结开发集及受保护子集的成功、碰撞和突破门槛，通过后才运行同场景的原 SAC 与新候选。独立验收要求总体成功率不低于原模型、碰撞率严格下降且不超过 5%、突破率不增加，同时每个连续 200 场景块分别满足成功率保持和碰撞率严格改善及预算；总体碰撞率 Wilson 95% 区间上限也须不超过 5%。全部通过才产生 `qualified.pth`。该流程检验固定模型的跨场景表现，不代表多个训练种子稳定或全局最低碰撞率，不自动开展正式实验。

启用预测兼容性分支、突破恢复课程或碰撞最小化目标后，`train/train_mappo_performance.py` 的开发集筛选和最终验收也要求突破率不增加，并检查原受保护子集。这项条件写入冻结标准；旧运行若未包含它，不能沿用原目录悄悄改变标准后继续。

验收入口可传入 `--comparison-checkpoint`，在同一批未使用的独立场景额外运行上一版模型并记录逐场景配对的成功、碰撞、突破变化。该对比不改动预先冻结的原基线验收标准；开发集未通过时不会运行独立验收或这一额外对比。

### 混合推力与联合拦截预测（性能开发）

`enable_mixture_compatibility(points=5, joint=True)` 在同一轮候选消息上预测
`theta=0,0.25,0.5,0.75,1` 的实际融合推力轨迹，并保存所有艇对的网格最近距离。
`points=9` 将间隔细化为 0.125，三艇加上各自原意向后共有 1,000 种组合；
网格大小随 checkpoint 保存，训练和部署使用相同配置。
原有 18 维关系编码输入保持不变；端点轨迹与混合网格共用一次动力学推演。
旧 checkpoint 默认关闭此功能。启用后交换原始 Actor 观测，用当前网络重算各艇门控意向，
PPO 保存和复用原始预测特征，不复用旧神经隐状态。

联合模式枚举网格及原意向的组合。三艇、五点网格共有 216 种组合，以名义碰撞距离
惩罚和门控改变量选取组合，靠近攻击艇的艇具有更高改动代价。保持原意向时连原始
高斯均值也保留；修正进入采样分布，不在采样后覆盖推力。离散组合选择分段常数，
梯度不穿过 argmin；原意向、增益及实际条件概率中可导的部分继续参与 PPO。
完全同代价的离散组合按当前固定艇序取第一个，不宣称这种对称退化情形具有严格的置换等变性。
每步最多允许 10,000 种组合，这项开发实现不适用于任意大的编队。

`task_prediction=True` 进一步用当前观测的攻击艇位置、地速做短期匀速外推，
比较各混合轨迹的最近拦截距离及窗口末距离。在保持名义队内间距时，惩罚团队
最佳拦截机会的退化。预测不读取未来海流、未来攻击动作或 Critic 状态；匀速外推、
网格插值及保持推力均是近似，真实成功、碰撞和突破标签仍全部来自完整环境回合。
局部梯度模式 `joint=False` 保留为开发选项，不能据此假定性能改善。

可选 `terminal_prediction=True` 检查预测碰撞是否发生在预计捕获之前。它使用同一
当前观测的匀速外推，以 4 米预测半径估计各网格动作的首次捕获时间，在其后保留
0.4 秒余量，并向上取到预测窗口的四分之一边界；没有预计捕获时保留整个窗口。
原环境的 5 米捕获与碰撞阈值及真实终止判定均不改变。额外特征保存前三个前缀窗口
的艇对最近距离和归一化捕获时间；非网格意向取相邻两个网格动作中较晚的时间，
任一邻点没有预计捕获就保留全窗口。组合中的任一艇预计完成捕获可缩短整个团队
的名义预测窗口。这个近似可能出错，不能当作安全证明或成功标签；必须检查真实
完整回合的碰撞和突破。试验入口为 `probe_mappo_mixture.py --joint --terminal-prediction`。
旧模型及原 SAC 基线默认关闭；开启后须重新采样与验收。

`probe_mappo_mixture.py` 仅使用编号不小于 100000 的训练场景做固定候选的配对检查，
保存来源与候选哈希、配置和逐场景结果。该检查不赋予验收资格。正式的冻结候选检查可用
`qualify_mappo.py --min-success-rate .99 --max-collision-rate .01`，先通过开发门槛，
再在未用场景上要求总体成功率至少 99%、碰撞率至多 1%，并保留原有突破率、
分块和置信区间检查。区间与点估计分开报告。训练续跑和独立验收都会逐种子检查
历史验收记录；切换工作树、改动起始种子或仅部分重叠，都不能将已经用过的场景
重新标为独立验收。

`qualify_mappo.py --development-only` 用统一开发清单比较冻结候选，不消耗新验收
场景。若用户允许在多轮无改善后交付稳定的最佳实测结果，`--report-nonqualifying`
可继续测量尚未通过开发门槛的候选；原有严格验收条件与 `performance_passed` 含义
保持不变，开发或独立门槛失败都不会产生 `qualified.pth`。报告保存来源 checkpoint
哈希，便于确认多批复测使用相同模型。最佳实测候选及其未达标指标应单独说明。
`--development-results <已完成的冻结评估目录>` 可复用开发结果；入口逐一核对来源
模型、冻结模型、原基线和评估清单的哈希、完整有序种子及逐场景指标，重新计算
验收判断。策略修改、未完成结果或缺少清单指纹的旧结果不能复用。独立场景仍须
重新采样并通过未使用检查。

本轮性能开发优先追求独立评估成功率至少 99%、碰撞率至多 1%。若连续至少三个
实质性优化方向在统一开发场景中没有可靠收益，可按实际平台期结束：先保留原基线
的成功表现，再比较成功率、碰撞率和突破率，列出各项取舍与成对场景变化。默认按
成功率优先、相同成功数时碰撞更少、再比较突破数选择交付候选，不使用隐藏的加权
分数；小样本训练探针不单独构成平台期证据。选定后冻结参数，在三批互不重叠、
未参与调参的新场景中复测同一个模型，并与同场景原基线比较。三批一致性描述的是
固定模型的跨场景稳定性，不代表多个独立训练种子的稳定性。资源错误和未完成评估
不能计作无改进，未达到的严格条件继续报告失败；有限搜索不能证明全局最优。
独立报告用 `--audit-episodes 6000 --report-batch-size 2000` 预先固定三批场景，
分别记录三种真实事件的次数及 Wilson 95% 区间。分批报告不改变原有 200 场景
分块检查、总体 99% / 1% 目标或突破率门槛。

已查看的独立场景可明确转入新的开发清单，并继续保护原场景子集；新的独立验收
必须避开这些场景。扩大清单后，`--breach-budget` 用于显式匹配新冻结基线的实际突破率，
不重设 Actor 或已有乘子；新旧预算记录在 checkpoint 中。`--breach-cases` 控制每批
恢复训练的不同突破起点数量，`--recovery-cost-baseline` 启用已有的留一未来成本及突破
基线。训练指标分别报告其与 Critic 的均方概率误差，其他未来不包含当前轨迹的结果。

性能训练入口支持同名的成功率、碰撞率验收参数；`--collision-budget` 可显式修改
新运行的训练成本预算。训练预算与验收点估计目标分别记录，已有目录不允许悄悄更改
冻结标准。使用此前失败候选继续训练时，应重新采样并重新验收。

`--contextual-prior` 在现有 Adapter 特征上新增一层零初始化的线性头，令预测修正的
增益乘以 `2*sigmoid(context_head(features))`。初始因子严格为 1，原有动作分布和
Adam 状态保留；后续因子由完整回合的任务、碰撞和突破优势通过同一个 PPO 目标学习。
它允许不同拦截状态具有不同修正强度，梯度无需穿过离散组合选择。原始预测信号为零
时，这个分支对均值没有影响。

同时指定 `--context-only` 可仅训练新增增益头，原 Actor 参数保留在零学习率组中，
权重不变，Critic 正常学习。配置和优化器分组随 checkpoint 恢复；续训时省略这两个
初始化开关。使用该模式需要另行进行完整性能验收。旧 checkpoint 默认关闭，原 SAC
基线显式关闭；仅适用于全局标量增益的 `refine_mappo_prior.py` 不接受此类模型。

若只训练增益头不足以改进拦截，可在新的续训目录指定 `--train-full-actor` 恢复
原 Actor 各部分的正常学习率分组，并配合显式的基础与预测学习率。切换时动作分布
及已有 Adam 状态不变，之后才用新采集回合学习；开发稳定计数与验收资格重新计算。

### 新增预测分支的 KL 校准

新增物理预测分支可先通过 `calibrate_mappo_prior.py` 初始化。它从不含该分支的 theta 空间 checkpoint 采集普通训练回合，核对保存的行为概率后计算单位增益的联合潜变量 KL：`K_1 = mean_t sum_i 0.5*(signal_i/std_i)^2`。将增益设为 `min(1, sqrt(target_kl/K_1))`，使新增门控均值的平均变化也遵守原 PPO KL 上限。提案、原 Adapter 和标准差参数保持不变；增益随后仍由 PPO 概率梯度训练。潜变量 KL 上界也约束裁剪后分布的 KL，但不保证任务指标改善。

初始化和配对检查使用互不重叠的训练场景；旧概率不匹配、保留评估种子或课程样本会被拒绝。只有成功率不降、突破不增且实际碰撞减少时才保存待训练候选。局部改善与最终达标分开记录：尚未满足碰撞预算的候选只能继续训练，不能成为 `qualified.pth`。冻结开发门槛、独立验收和正式实验限制均不改变。

已有分支可用 `refine_mappo_prior.py` 做一次有界的增益方向检查。它保持神经网络不变，用保存的实际门控概率和完整回合碰撞、突破事件计算 PPO 方向；按完整训练回合拆分拟合与留出数据。固定回溯只在拟合部分选一步，再在留出部分检查一次，方向不一致时不更新、不运行后续环境比较。通过后才进行另一批训练场景的确定性配对检查，只有成功率不降、碰撞严格减少且突破不增才保存候选。该工具不搜索验收种子，也不把 surrogate 改善当成性能达标。

其 `--gate-head` 模式联合调整现有门控最后一层和物理增益，提案与特征提取器在这一步固定。对旧动作的 PPO 概率梯度用带正则的高斯 Fisher 矩阵预调节，在拟合回合上投影到任务、碰撞、突破 surrogate 同时改善的方向，再限制条件联合 KL。留出回合要求综合目标和碰撞 surrogate 改善，并报告突破变化；它们仍是有采样误差的训练估计，真实突破率由后续配对轨迹与冻结验收决定。此模式不改变 Actor 的正常可求导计算图；随后完整 MAPPO 更新仍重新计算关系编码并训练全部策略参数。它不是对 Q 求动作梯度，也不增加新的执行网络或推力过滤器。

`cost_monte_carlo_targets=True` 只决定碰撞价值头的标签；若 Actor 也要使用未折扣完整回合事件优势，须同时指定 `--cost-gae-lambda 1`。此时 `A_collision = C_episode - V_collision(s)`，避免不准确的时间差分估计影响早期动作的成本信号，但方差可能增大，可通过更多独立训练回合降低采样噪声。任务优势和碰撞优势仍组合后统一标准化，碰撞预算不变。

### 保留任务收益的突破约束

`breach_constraint=True` 在原任务收益和碰撞约束上增加 `V_breach(s)`，使用真实完整回合的突破事件构造未折扣 `A_breach`。综合优势为 `A_task-lambda_collision*A_collision-lambda_breach*A_breach`，仍只统一标准化一次。它保留原任务奖励，不是 `minimize_collision` 的事件替代目标，两种模式互斥。突破与碰撞即便同时发生也分别计入对应成本，预测风险不能代替真实标签。

`--breach-constraint` 以冻结原基线开发集的突破率为预算，新增乘子默认从当前碰撞乘子的数值初始化；这只是同为事件概率成本的显式起点，不是最优乘子的估计。每轮 PPO 内两个乘子固定，之后分别用普通完整回合的真实事件率更新。失败恢复课程不参与预算统计；其突破基线可使用同一起点、同一探索上下文的其他独立续跑，并排除自身未来结果。`guard_task_surrogate` 同时检查普通样本上的任务、碰撞与突破 surrogate，失败时恢复 Actor 和 Adam。该检查不能代替独立场景的实际突破率验收。

迁移增加突破价值头并保留已有 Actor、任务/碰撞价值头和优化器状态。部署仍只调用 Actor，新的价值头不进入执行链路。

### 裁剪门控的执行概率

可选 `censored_gate_likelihood=True` 保持 theta 空间高斯采样和裁剪动作不变，把 PPO 门控概率改为执行动作的混合分布：`theta=0` 使用 `log Phi(-mu/sigma)`，`theta=1` 使用 `log Phi((mu-1)/sigma)`，内部使用 Normal 密度。原始采样 `gate_raw` 仍保存；新旧概率、联合 ratio、KL 和熵都采用同一模式。熵按内部连续密度及两端概率质量计算，极小尾概率使用 `log_ndtr`。它不是将裁剪值直接代入 Gaussian 密度。

该处理依据 [Clipped Action Policy Gradient](https://proceedings.mlr.press/v80/fujita18a.html) 对等效端点动作的条件期望原理，消除对实际执行无影响的潜变量噪声。原论文的无偏性和方差结论针对策略梯度估计；不能据此声称 PPO 裁剪后的每轮优化或实际任务指标必然改善。`enable_censored_gate_likelihood()` 保留 Actor 权重及 Adam 状态，旧 checkpoint 默认 False；切换后重新采集数据。串行、批量采样均逐步保存概率模式，buffer 在优化前拒绝旧 Gaussian 概率、端点概率混用或模式不匹配，旧记录缺少模式时只按原 Gaussian 模式解释。实际突破和碰撞仍用冻结标准检验。

### 风险恢复分支的学习信号

可选 `curriculum_cost_baseline` 利用同一起点、同一探索上下文的独立实际续跑构建成本基线：评价某条续跑时，排除该条轨迹自身的结果，使用其余续跑的实际碰撞频率。该基线在前 `curriculum_baseline_steps=20` 步线性衰减回原状态价值，避免轨迹逐渐分离后一直共用起点统计。完整未折扣的真实成本目标保持不变；正常起始回合保留原状态基线，乘子仍只由正常回合更新。此功能要求成本 GAE 为 1 且使用完整回合成本目标。

`training.branch_gate_steps` 可限制加宽门控探索只发生在续跑初期；0 保留整段续跑加宽的旧行为。每一步保存实际探索尺度，旧概率与 PPO 重算使用同一尺度。`training.branch_max_cases` 可限制独立起点数，使给定分支预算能覆盖同一起点的多个独立未来。

`--breach-branches` 另行分配突破恢复预算。选择真实训练突破回合后，找出预测分支首次令实际门控变化超过 0.05 的控制时刻，并回退 5 步，在拦截路径被改变之前重新采样；没有有效预测干预时从回合起点开始。它不修改环境终点、碰撞阈值或成功判定，不使用验证/验收种子。保存的已执行前缀必须精确复现原状态。单纯从突破终点前几秒采样，可能已经没有可恢复的拦截位置。

`curriculum_reward_baseline` 对任务收益增加独立续跑基线，要求任务折扣和 GAE 都为 1。先排除本条续跑的未来回报，平均其他独立续跑的实际完整任务回报；在第 t 步仅减去本条轨迹已经发生的奖励，再与原状态价值按同一时间窗口衰减混合。它不把一个未来结果套给未执行动作，也不把本条未来标签放入自身基线；任务收益及成本目标本身保持不变，两个优势仍按原乘子合并后统一标准化。任务基线误差另行记录。

`diagnose_mappo_recovery.py --early-breach-update` 提供一次有界微调：收集正常回合、碰撞恢复和早期突破恢复，确认存在成功续跑且独立任务基线的误差改善后，才执行一次受保护的 PPO 更新，再进行小规模新训练场景的成对比较。该入口不会自动循环训练或启动正式实验，局部改善仍需冻结后通过完整性能验收。

可选 `guard_task_surrogate` 在完整批次 KL 和综合优势检查之外，要求正常回合上的任务及负成本 PPO surrogate 均不下降；不满足时同时恢复 Actor 与 Adam 状态。该检查只约束当前经验批次，不能作为真实成功率改善的证明。成本基线误差和两个 surrogate 的变化分别记录。这些选项与相容性分支独立，不因启用后者自动更改原训练目标或碰撞乘子。

### 在保持任务表现的约束下最小化碰撞

`--minimize-collision` 将性能训练的主目标显式改为最小化真实队内碰撞概率，同时约束成功率不低于冻结原基线、突破率不高于冻结原基线，并保留 5% 碰撞预算。原先的“最大化任务回报且碰撞率不超过预算”不要求在预算以内继续降低碰撞；新模式在碰撞乘子为零时仍保留单位碰撞成本。原有任务回报继续记录并拟合价值头，但不进入本模式的策略优势，不能将这个模式描述为原奖励不变的实验。

配合 `--success-floor .99` 可将训练中的成功约束显式收紧到 99%，该值不能低于冻结
原基线，续训保留 checkpoint 中的约束。它可从已有突破约束模型迁移：已有突破价值头、
Actor 和对应 Adam 状态保留，只新增成功价值头，并按事件目标的单位初始化乘子。
价值头的参数顺序与新建模型一致，防止恢复时将成功与突破头的 Adam 状态互换。
启用恢复成本基线时，成功及突破优势也使用其他独立未来的留一估计，完整回合的
实际事件标签保持不变。

策略优势为 `A = mu_success * A_success - mu_breach * A_breach - (1 + lambda_collision) * A_collision`。三种事件优势均由本条实际执行轨迹的完整、未折扣结果减去采样时的状态价值得到；成本 GAE 固定为 1，不将不准确的未来价值 bootstrap 当作碰撞标签。新增成功和突破价值头只用于训练。成功、突破、首次队内碰撞沿用环境的实际判定，突破与碰撞同时发生时分别计入两个指标。

每批 PPO 更新内三个乘子固定，所有 epoch 完成后各更新一次：成功乘子按 `success_floor - observed_success` 调整；突破乘子按 `observed_breach - breach_budget` 调整；碰撞乘子沿用实际碰撞率与预算之差。全部乘子只用正常初始分布的完整回合估计，失败前状态的课程分支不参与约束概率统计。原分支仍以自身重新执行的真实结果参与策略学习。三个事件优势先按上述权重合并，再统一标准化，避免分别标准化改变乘子的含义。

转换保留 Actor 和其 Adam 状态、原有价值网络参数与 Adam 状态；新增事件头以冻结基线率初始化并用新采集回合预训练。由于优化单位由原任务回报变为事件概率，碰撞乘子重设为 0，成功与突破乘子分别从 1 和 5 开始，事件乘子步长均为 10；这些是明确的训练设置，不是性能结论。门控、提案、关系与协调网络仍由两阶段 PPO 概率梯度更新。转换只执行一次，续训省略开关。

本模式用新的运行目录固定目标和门槛。开发集及原受保护子集均增加“突破率不高于同场景基线”的验收条件；已有基线子集的突破率从其冻结逐回合 CSV 恢复，不重跑基线。成功率保持、碰撞率严格下降且不超过 5% 的要求不变。候选冻结后的独立验收仍与相同新种子的原基线成对比较，包括突破率。降低碰撞但让目标更多突破的模型不会通过。

`--environments-per-worker 4` 可在每个训练进程内批量计算多个独立环境的候选、预测与网络前向。各环境分别保存 NumPy、Python、Torch 随机数状态及完整实际动作，艇对预测不会跨环境混合。批量矩阵计算的浮点舍入可能积累为轨迹差异，因此不承诺与逐环境采样逐步相同；仍保存并重算原始采样概率，课程前缀必须精确恢复。所有确定性开发验证和独立验收保持原来的逐环境执行路径。

`--branch-gate-scale 4` 为风险恢复分支设置显式的探索上下文 `kappa=4`，其门控采样标准差为 `kappa*sigma`。正常起始回合保持 `kappa=1`，两类回合共享策略参数，提案分布不受此开关影响。每条转移保存实际使用的 `gate_scale`；旧概率、当前概率、熵与完整批次 KL 都在同一个已保存的上下文下计算，不能用扩大方差采到的动作配上原窄分布的概率。确定性执行仍取相同均值。本设置扩展训练分支的动作覆盖，是明确的课程探索条件，不是避碰规则或执行时的安全保证；正式对照应统一或披露此条件。默认尺度为 1，旧 checkpoint 和原部署行为兼容。
