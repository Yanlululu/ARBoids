# 自适应重选间隔：第四次确认前的有限修复

第三轮在512个全新六艇场景中成功512次、零碰撞，规划p95为136毫秒。相对CBF和同参数1秒短时消融的耗时改善分别为14.36%和16.58%；相对较强2秒短时方案为9.39%，98.333%配对区间排除零，但尚未达到四项主要对照全部至少10%的冻结标准。原结果与协议保持不变。

## 依据和唯一候选

已有两批128场六艇数据中，真实机动系数1.5这一格，2秒重选持续候选方法均比1秒重选快（12.58比14.81秒；10.82比12.06秒）。高机动格中1秒方法整体更好。新候选仅调整重选间隔：沿用原来的因果运动估计，每次开始规划时若估计机动系数小于1.75，使用2秒执行区间，否则使用1秒；执行区间内不切换间隔，控制反馈仍每0.2秒更新。阈值为原来两档相邻机动系数的中点，不搜索更多阈值。初始估计2.25，因此初始间隔仍为1秒。后续推演20秒、候选策略族、评分、捕获裕度和安全过滤保持第三轮版本。

同参数短时消融采用完全相同的在线估计和间隔调整规则，仅去掉后续推演。较强的固定2秒短时方案、CBF、固定守卫策略继续保留。第三轮1秒长时版本为次级版本对照。

## 开发与独立确认

前三轮已经观察过的768个六艇场景用于有限开发，完整比较新增自适应长时及匹配短时配置；之前冻结的相同场景对照结果可直接用于配对分析，明确这些是开发数据。先验证固定间隔退化情形与第三轮实现一致，以及在线估计只更新一次、间隔仅在规划时改变。

开发达到成功率和效率要求后，重新单独测量32个旧六艇完整回合的串行/五进程并行等价性和时延。通过p95低于200毫秒后，再冻结代码、协议、分析和新场景名单。

下一次独立确认预定1024个全新六艇场景，每档机动系数256个。种子为203160000＋机动档索引×10000＋重复编号，噪声种子加1000000；确认前检查与全部已有场景不重叠。一次完整运行，不根据中间结果改参数或停止。

主要比较为CBF、自适应间隔短时消融、固定2秒短时方案、固定守卫策略；全部须满足至少10%的平均封顶耗时改善、配对分层10000次自举区间排除零改善、观察成功数不少且碰撞数不多、配对成功率差保守下界至少−3个百分点。未捕获仍全部按80秒计，原任务成功定义不改。考虑四次确认机会，本轮采用98.75%区间；前述三轮结果按各自原协议保留。所有主要比较必须同时通过。
