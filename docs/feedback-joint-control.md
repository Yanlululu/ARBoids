# 反馈一致的连续联合控制

## 要修复的两项结构问题

原候选预测假设同一推力保持整个时域，而实际门控每 0.2 秒重新选择；
原动作又被限制在每艇 Boids 与学习动作之间的一条线段。本实现分别消除
这两个假设，不修改原始对照、奖励、观测和终止规则。

新控制器以固定长度的反馈执行段为单位选择策略参数。在一个执行段内，
参数不变，但 Actor、Boids、联合 CBF 安全优化都每 0.2 秒用新观测重新计算。
预测逐步调用与实船控制相同的反馈函数；预测到本执行段末即结束，不把
下一次尚未作出的外层选择假定为已知。外层选择只在执行段结束后重新进行。

安全优化变量是全部防守艇的 `2N` 个左右推进器推力，范围均为
`[-500,1000] N`，不加入融合线段约束。原始学习策略与 Boids 的融合动作
只作为代价中的参考推力。使用现有 CBFpy 配置与原始 CBF 强对照一致的
安全距离、屏障增益、松弛权重和求解容差；不宣称随机海流下的绝对安全。

## 固定实现选择

- 控制周期 0.2 秒。开发仅比较 5 或 10 周期两种执行段，即 1 或 2 秒。
- 反馈策略参数有五种：原门控、门控整体加 .25、整体减 .25、最近拦截艇
  加 .25 而其余减 .25、最近拦截艇减 .25 而其余加 .25。每周期用当前
  位置重新确定最近艇，门控限制在 [0,1]；连续安全修正不受此线段限制。
- 每次先预测原门控＋CBF 反馈。如果其最小间距低于 8 米或出现预测
  失守，则评估其余四种参数。没有风险时保留原反馈。
- 固定选择顺序：避免预测碰撞、避免源码失守、优先预测捕获，随后最小化
  终点最近拦截距离、保护区方向的防守余量损失、7 米内接近惩罚及参考推力
  偏离。具体无量纲公式见实现，不根据确认集改动。
- 预测只接受公开测量：艇位、航向、地速、转速、当期 Actor 观测与 Boids
  提案、仿真时间，以及控制器自身已发出的历史推力。不得读取未来随机数、
  环境快照中的真实相对水速或隐藏攻击艇参数。
- 名义攻击艇敏捷度固定为 2.25，预测海流和 APF 扰动为零。原数值环境
  的速度缓存在积分末滞后一小步，用已知历史控制和名义动力学做时间对齐；
  VRX 接口不使用这一特定数值缓存校正。
- 原始源码逐字节保持不变；新控制器和验证入口使用独立文件。

## 本次固定验证顺序

1. 结构测试：零扰动下，包含多次段末重规划的预测和实际命令／轨迹一致；
   预测不改变环境随机流；连续输出能够离开融合线段；重置后无跨回合状态。
2. 开发集：既有 16 配置中每格固定哈希选 4 场景，共 64 个。只比较上述
   两种执行段长度，按成功数最多、碰撞数最少、控制计算较少的顺序选一次。
3. 冻结参数后，在新的 128 个原三艇场景及 16 配置×16 个场景上运行。
   共 384 个新场景；固定新种子段，原始、瞬时联合、旧预测联合、CBF、
   新完整方法，以及去掉反馈一致性／去掉连续动作空间两个消融共用初态
   和随机流。不得因结果增加样本或修改方法。
4. 在已有 60 个失败前状态上恢复，检查修复能否保留 CBF 的动作空间收益；
   这些是开发诊断，不计为新确认场景。
5. 独立测量整个控制链的中位数、95/99 百分位、超时比例，区分首次 JAX
   编译、规划周期和普通反馈周期。接入 VRX 使用相同反馈接口，并作实际
   Gazebo 冒烟运行；不与此前 32 组 VRX 的统计混合。

这里的“预测与执行一致”指相同反馈律和计划更新时刻，不等于可以预知海流、
攻击艇模型偏差或观测误差。报告将分别给出结构一致性、扰动下预测误差及
任务性能，只有实际通过的部分才记为已解决。
